SOS Pendant

A wearable emergency SOS pendant device designed to keep people safe in critical situations. One press of the button instantly sends the wearer's real-time GPS location to pre-registered emergency contacts via SMS and push notifications. Features include fall detection using an onboard accelerometer, 24/7 live monitoring dashboard, two-way audio communication, geofencing alerts, and battery-efficient always-on mode. The companion app (React Native) lets guardians track location history and configure alert thresholds. Backend built with Node.js, WebSockets for live updates, and an ML model for anomaly detection in movement patterns.
